# PT-035 - The escapes the export adds

Found 2026-10-29 in use on another repository's file: after a sync the file held `\+`, `\~` and `\)` the export had
written and the normalizer left. Status: completed 2026-10-30.

## Evidence

Fixture 16, made by [probe.py](PT-035/probe.py) ([probe.out.txt](PT-035/probe.out.txt)), invented text: the export
escapes a literal `+` or `~` in prose (a `~~strike~~` stays markup), each tilde of a literal `~~~`, and a `)` after
digits before a space (`2013\) and`, not `2013).`); it consumes a `\(` or `\)` the file holds and writes the file's
`\+`, `\~`, `\---`, a line-start `\+ ` and `\#` back escaped. The `ExportEscapes` tests in
[tests/test_normalize.py](../../tests/test_normalize.py) pin the pair and the line-start rule.

## Decided here

- The normalizer unescapes `\+`, `\~`, `\(` and `\)` with the rest, so a deliberate one in the file is dropped on
  pull as fixture 07's `\_` is; the features row says a dropped escape can turn text into markup.
- A line-start escape stays only where the character would make a block: a bullet or heading marker before a space
  or the end, a quote mark, an ordered marker of up to nine digits before a space, and the rule or fence openers;
  `\+1` or `\#tag` is prose and is unescaped, so the export's `\+15550100` and the file's `+15550100` agree. The gate
  found the first form of the rule let `\---`, `\***` and `\~~~` through, and that the export writes `\~\~\~`.
- The first text of the fixture was modelled on the file the defect was found in; the gate found one line taken as
  it was, and the pair was made again from invented text.

## Left open

- A state file from before this change holds a snapshot with these escapes, so its first sync reads the Doc as
  changed on such lines, once; a line edited in the file at the same time reads as a conflict. This repository's
  state file was made again in this change.
- Whether the export ever writes `\~\~x\~\~` for a literal `~~x~~` typed in the Doc, which a pull would turn into a
  strike, was not tried.
