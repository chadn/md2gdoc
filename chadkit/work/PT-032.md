# PT-032 - Adopt the shared documentation gate by reference

Serves PG-03 and PG-04: prose a reader acts on here, the docs under [docs/](../../docs/), the
[README](../../README.md) and the other classes the local gate file lists, gets read by the shared documentation
focus, user-ck's `chadkit/workflows/docs-gate.md`, on the language model it names, instead of by the QA gate's
correctness read alone; the fidelity claims in [docs/features.md](../../docs/features.md) are the kind of prose it
exists for. This repository keeps no copy of the shared wording.

## Mechanism

1. [chadkit/config.yaml](../config.yaml): `workflows.docs-gate.from: user-ck@main`, the shared file as merged into
   user-ck's main. Done 2026-10-28 by Chad, uncommitted when this task was written.
2. [chadkit/workflows/qa-gate.md](../workflows/qa-gate.md): a `## Documentation` heading, the local parts the shared
   file's Local list asks for: no prose format beyond the shared two, one audience line per document class the
   repository holds (the heading is that list), no local questions, no variants, there being no `docs-model`
   variant to drop. Done 2026-10-28.
   The two tracked issues' tags, `#source-links` and `#exec-summary`, get their rows in
   [chadkit/language.md](../language.md), with rows for the two terms they use: `chadkit doctor` notes a tag with
   no row, and [scripts/gate-checks.sh](../../scripts/gate-checks.sh) fails on any note but the two it excuses.
3. The linked-references check is already in [scripts/gate-checks.sh](../../scripts/gate-checks.sh), so the
   reviewer leaves links to it.
4. From then on, a gate record on prose carries `focus documentation`, the revision of the shared documentation
   focus followed, the language model and the tokens, as that file's Record asks. The first run is the gate record
   of the next prose change, which may be this task's own commit, since the local gate file is a gate path.

Done when the heading is in the local file and one gate record here carries `focus documentation`.
