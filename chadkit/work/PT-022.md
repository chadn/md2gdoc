## Verification: not pursued

The app is used unverified: the consent screen shows "Google hasn't verified this app", **Advanced** then **Go to
md2gdoc (unsafe)**, 100 users for the project's lifetime (setup.md, Secondary-account setup). Verification would mean
brand verification and, for a restricted scope, possibly a security assessment, none of it needed to use the app. If
the console shows a verification request pending from the answers above, leave it; record here what Google did with it.

## Script change, done 2026-10-23

`init` only created a Doc; nothing attached a file to an existing one. `init FILE --doc DOC_ID` now writes the Doc's
text into a new or empty FILE and the state file from the Doc's id, link and version; `--json` reason `attached`.
